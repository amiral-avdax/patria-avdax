# Site de recrutement PATRIA [AVDAX]

Site statique, deux langues :
- index.html : version anglaise (racine)
- it/index.html : version italienne
- crest.png : blason

## Mettre a jour le site (Amiral)
1. Modifier le texte directement dans index.html (EN) et/ou it/index.html (IT). Toujours changer les deux langues ensemble.
2. Sur GitHub : ouvrir le fichier, icone crayon, modifier, "Commit changes". La mise en ligne GitHub Pages se fait seule en 1 a 2 minutes.
   En ligne de commande : git add -A && git commit -m "maj" && git push
3. Les liens entre pages sont relatifs : ne pas les remplacer par des liens commencant par "/".
